# Raphael Jay Bernardo

**Shopify Developer**

## Direction

Keep the wording straightforward, personal, and focused on finding work. The visual design should be modern and distinctive while staying light. Use the full name and role. No initials logo, grand slogan, or promise of business results.

The introduction should tell visitors what Raphael works on and that he is open to a role. Let projects, screenshots, and source code demonstrate the skills.

## Visual style

- Warm white `#f9f8f4`: page background.
- White `#ffffff`: project and content surfaces.
- Charcoal `#262c25`: primary text.
- Muted green gray `#62695e`: supporting text.
- Terracotta `#b34120`: links, actions, and restrained emphasis.
- Geist for headings and text; Geist Mono for project labels.
- Body copy: 1rem (16 px at default settings); supporting text and controls: .875rem (14 px); short labels: .75rem (12 px) minimum. Do not shrink mobile copy below these sizes to fit the layout. Allow wrapping or change the layout.

Use oversized personal typography, italic serif accents, layered project screenshots, peach and sage surfaces, rounded controls, and clear spacing. Avoid falling back to a plain two-column introduction. Keep project browsing and contact easy. Use subtle, reduced-motion-aware interactions to explore actual work. Respect keyboard navigation and reduced-motion preferences.

## Writing

Plain and honest. Prefer “Shopify Developer,” “Projects I've built,” and “Open to work” over marketing language. Avoid claims of seniority, expertise, revenue improvements, or production scale without evidence. Clearly label sample screenshots or data.

## Theme choice and motion

Light remains the default. Visitors can switch to a warm charcoal palette using the header toggle; the choice persists across reloads and case studies. Both palettes share the same layout, readable type sizes, and project evidence. Actual project screenshots keep their original colors.

Apply the saved theme before the page paints. Theme controls must remain keyboard accessible, work without browser storage, and synchronize across tabs.

The featured banner advances every six seconds, with an explicit pause/play control. Hover pauses rotation temporarily; focusing project content or using the manual arrows stops rotation until the visitor restarts it. Disable automatic rotation by default when reduced motion is requested, and suspend its timer in background tabs.
